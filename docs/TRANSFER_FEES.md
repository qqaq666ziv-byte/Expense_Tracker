# 轉帳手續費

新建轉帳的金額為來源帳戶扣款總額，選填手續費從目的帳戶入帳扣除。
例如轉帳 1,000、手續費 15：來源 -1,000、目的 +985、支出 +15。
手續費必須小於轉帳金額。舊紀錄保留原有規則（來源另扣手續費），
透過 `feeMode`／資料庫 `fee_mode` 區分，避免既有餘額被重新計算。
編輯舊紀錄仍沿用其原始規則；新增紀錄使用 `destination-net`。
手續費和轉帳是同一筆資料，編輯、刪除、離線儲存、同步與 JSON 備份一起處理；
清空手續費欄位代表 0。既有未帶 fee 的紀錄視為 0。

手續費計入總支出、洞察、趨勢及整體預算，獨立顯示「手續費」統計分類，
不額外建立交易，也不計入既有使用者分類預算。CSV 轉帳匯出包含 fee 與 fee_mode 欄位。
