# 柴柴記帳 Product / UX parity audit

更新日期：2026-08-24

## Audit 範圍與證據

- 舊 production：`https://shiba-expense-tracker.vercel.app`，2026-08-24 以桌機與 390 × 844 手機 viewport 實際操作。
- 舊版 source：commit `49bbd22` 的 `Dashboard.tsx`、`Insights.tsx`、`Savings.tsx`、`BudgetPlanner.tsx`。
- v3 rewrite：`origin/main` commit `732ea22`，本機以乾淨安裝、mobile viewport 與真實瀏覽器操作。
- 使用者提供的三張畫面：舊版極速記帳、donut 分類占比與面積趨勢圖。
- 本次 redesign：`codex/ux-product-experience`。

這不是單純 source diff。判斷依據是第一次使用者是否能找到入口、完成任務、理解結果，以及 mobile 上的實際操作成本。

## Old vs v3 vs redesign

| 體驗 | 舊 production | v3 rewrite | 本次決策 |
| --- | --- | --- | --- |
| 主要入口 | 「極速記帳」就是產品首頁 | 首頁先顯示總資產與帳戶，記帳表單排在後面 | **恢復並改良**：記帳成為第一入口與第一視覺焦點 |
| 金額輸入 | 巨大金額區、主角感強 | 一般 label + input | **恢復並精修**主角式金額輸入；`type=text` + integer-first mobile keypad、自動千分位、按需小數／正負切換，保留兩位小數與安全上限驗證 |
| 支出／收入 | 直接大切換 | 保留切換但表單感較重 | **融合**舊版視覺直接性與 v3 正確資料模型 |
| 分類 | 圖示大按鈕、預設內容有特色 | select，下拉選單；預設圖示較通用 | **恢復**可點分類網格與舊版核心圖示，擴充醫療、學習、人情、投資 |
| 付款／帳戶 | chip 很快，但把信用卡混成付款方式 | 正確拆出 Asset Account，但使用 select | **融合**：用 v3 Asset Account 語義重新實現 chip，避免把信用卡債務誤當資產 |
| 時間／備註 | 常駐、仍相對清楚 | 常駐並與四個主欄位並列 | **改良**：預設現在並收進可展開區，編輯時自動開啟 |
| 最近紀錄 | 搜尋、長按編輯提示 | 完整帳本、編輯、刪除、校正、漸進載入 | **保留 v3** 可稽核歷史與搜尋，改成明確編輯／刪除 label，不依賴猜長按 |
| 首頁總資產 | 一張首頁 hero | 首頁 hero + 帳戶分布 + 校正 | **移出首頁**到獨立「資產」，首頁只保留輕量今日支出 |
| 資產帳戶 | 本質是付款方式，自訂能力有限 | 正確帳戶模型，建立體驗像資料表 | **重做**成現金／銀行／電子支付／儲值卡／其他預設、資產 donut、帳戶明細與盤點調整 |
| 財務分析 | outlined 卡片、donut、面積折線有產品感 | 指標多但以進度條與長條圖呈現，帳戶分布也混入 | **恢復視覺精神**：細線框、留白、動畫 donut、面積折線；保留 v3 期間與前期比較 |
| 今日快照 | 可看近期紀錄，但 drill-down 不完整 | 有今日摘要，點擊只回首頁 | **改良**：直接回答今日支出，分類可點入期間交易，再回最近帳本 |
| 長期間／大數字 | 標籤可能擁擠 | 橫向長條仍可能塞滿 | **改善**：SVG responsive viewBox、智慧略過日期標籤、summary 才 compact、逐筆仍精確 |
| 儲蓄目標 | 柴柴存錢筒，有品牌感 | 正確 earmark 語義與超額保護 | **保留 v3 模型**，文案翻譯為生活語言並放進「規劃」 |
| 預算 | 獨立底部入口 | 與儲蓄同在規劃 | **保留 v3 IA**；再把固定收支納入規劃，符合「安排未來」mental model |
| 週期收支 | 固定開銷功能 | 藏在管理 | **恢復可見性**並搬到「規劃 → 固定收支」 |
| 登入／登出 | header 只有圖示與短文字，容易混淆 | 兩個 icon-only button + sync pill | **重做**帳戶選單，明確寫出身分、資料位置、同步狀態與登入／登出的結果 |
| 離線／同步 | 技術能力較淺 | 能力可靠但多個 banner 像控制台 | **保留 v3 核心**；正常狀態安靜，例外才顯示，技術錯誤收在「詳細資訊」 |
| Onboarding／FAQ | 無 | 無完整產品導覽 | **新增並精修**：正式產品介面上的建立 → 編輯 → 刪除互動教學，可跳過／暫停／續跑／分章重跑；另保留一次性情境提示、FAQ、同步與備份說明 |
| 品牌 | 柴犬 emoji、暖色、功能命名有特色 | generic amber Tailwind dashboard | **改良**既有 PWA mascot 為品牌 mark，採紙張、細線、生活工具排版，保留成熟系統 icons |
| 資料可靠度 | localStorage／早期 Supabase 模型 | owner isolation、outbox、衝突、tombstone、backup、recovery | **完整保留**，presentation 改版不穿越 domain seam |

## 恢復／融合／淘汰摘要

### 恢復

- 「極速記帳」作為核心產品入口。
- 支出／收入的大型直接切換。
- 金額主角、分類大按鈕、帳戶 chip。
- 舊版財務分析的 donut、面積趨勢、細框與留白節奏。
- 餐飲 `🍖`、交通 `🚗`、購物 `🛍️`、娛樂 `✨` 等新使用者預設體驗。

### 與 v3 融合

- 所有快速選擇仍寫入穩定的 `categoryId`／`accountId`，不退回文字欄位模型。
- 餘額校正仍是非收支調整；儲蓄配置仍不會降低總資產。
- 日期、money minor units、完整歷史、同步、刪除防復活與復原保護保持原語義。
- 自訂分類與圖案能力保留，但 UI 改寫為「表情圖案／簡約圖案」。

### 合理淘汰

- 首頁的大型總資產 hero、帳戶清單與校正表單。
- 以 select 為主的日常記帳流程。
- 只靠 icon 猜登入／登出、同步與重要操作。
- user-facing 的「向量圖示」「schema」「owner」「tombstone」「可稽核」「穩定 ID」等工程詞彙。
- 「管理」作為底部主入口；低頻設定改由帳戶選單進入。

## 尚存但不阻擋本次 UX release

- 既有使用者的分類圖示不會被自動覆寫；舊版圖示只成為新資料的預設，避免擅自改動個人設定。
- 無示範資料時趨勢圖只能呈現 empty state；README 截圖使用本機驗收資料。
- 第一級單一事件轉帳已由後續功能分支補齊；週期轉帳、多幣別、信用卡債務與銀行串接仍是明確非目標。
- 本次與後續轉帳功能工作均未部署 production、未套用待發布的 Supabase migrations，也未修改任何 production 財務資料。
